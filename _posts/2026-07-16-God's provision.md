## Step 1 — What Is a Blog Post File?

Every post on your site is a simple text file that lives in the `_posts/` folder. The file name matters a lot — it must follow this exact format:

```
YYYY-MM-DD-your-post-title.md
```

For example:
- `2025-03-20-god-is-faithful.md`
- `2025-04-01-what-easter-means-to-me.md`

The date in the file name controls where the post appears in your blog listing (newest first). The title part (after the date) becomes the web address for the post.

---

## Step 2 — The "Front Matter" Block

At the very top of every post you'll see a block surrounded by three dashes `---`. This is called **front matter** and it tells the site important information about the post.

Here is what it looks like:

```
---
layout: post
title: "Your Post Title Here"
date: 2025-01-15
author: Zayra
tags: [faith, prayer]
excerpt: "A short 1–2 sentence preview of your post."
---
```

Here's what each line does:

- **layout: post** — Leave this exactly as it is. It tells the site to use the post design.
- **title:** — Your post title. Put it inside quotes. This is what shows up as the big heading on the page.
- **date:** — The publish date. Use the format `YYYY-MM-DD` (year-month-day). This must match the date in the file name.
- **author:** — Your name. You can change this to anything you like.
- **tags:** — Words that describe your post, inside square brackets, separated by commas. More on tags below.
- **excerpt:** — A short summary (1–2 sentences). This shows up on the Blog page and in social media previews when someone shares your post.

## Step 3 — Writing Your Post Content

Everything *below* the closing `---` of the front matter is your actual post content. This is where you write!

You write in a format called **Markdown**. It is just plain text with a few simple symbols that control how things look. You don't need to know any code.

The next post in this series — **"Markdown Formatting: Bold, Italic, Lists, and More"** — walks through every formatting option with examples. But here are the most important ones:

### Making a Heading

Put one or two `#` symbols at the start of a line to make a heading. More `#` symbols = smaller heading.

```
## This becomes a big section heading
### This becomes a smaller sub-heading
```

### Making Text Bold or Italic

Wrap words in `**double asterisks**` to make them **bold**.
Wrap words in `*single asterisks*` to make them *italic*.

### Making a Bullet List

Put a `-` at the start of each line:

```
- First thought
- Second thought
- Third thought
```

Which looks like this:

- First thought
- Second thought
- Third thought

## Step 4 — Adding a Bible Verse

To make a Bible verse appear in the special teal-bordered quote style, start the line with a `>` symbol:

```
> "For God so loved the world..."

- John 3:16
```

It will look like this on the page:

> "For God so loved the world that he gave his one and only Son, that whoever believes in him shall not perish but have eternal life."

- John 3:16 *(NIV)*

The `>` can be used for any quote, not just Bible verses — but it looks especially beautiful for scripture.

## Step 5 — Saving and Publishing

When you are done writing:

1. **Save the file** in the `_posts/` folder with the correct `YYYY-MM-DD-title.md` name.
2. **Commit and push** the file to GitHub (using GitHub Desktop or the GitHub website).
3. **Wait about 1–2 minutes** — GitHub Pages will automatically rebuild your site.
4. **Visit your site** — your new post should appear at the top of the Blog page!

That's it. No buttons to click, no dashboards to navigate. Just write, save, and push.

---

## Your Publishing Checklist

Before pushing a new post, run through this quick checklist:

- [ ] The file is named `YYYY-MM-DD-your-title.md` and saved in `_posts/`
- [ ] The `date:` in the front matter matches the date in the file name
- [ ] The `title:` is filled in with your real post title
- [ ] The `excerpt:` has a short preview sentence
- [ ] You've chosen 1–3 `tags:` that describe the topic
- [ ] You've read through the post once for any typos
